# LATRVNCVLI

LATRVNCVLI is a digital implementation project for Ludus Latrunculorum, an ancient strategy board game. Its first ruleset will follow the Locus Ludi Seneca reconstruction. The rules specification and headless engine are the first milestones.

- [Locus Ludi rules publication](https://locusludi.ch/wp-content/uploads/2022/08/LUDUS-LATRUNCULORUM_rules_GB.pdf)
- [Roadmap](docs/ROADMAP.md)
- [Contributing](CONTRIBUTING.md)

Use Node.js 24 and install the locked dependencies with `npm ci`. The development commands are `npm run typecheck`, `npm test`, and `npm run build`.
