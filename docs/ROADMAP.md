# Roadmap

| Milestone | Scope |
| --- | --- |
| M0 | Historical specification and documented rule decisions |
| M1 | Headless rules engine |
| M2 | Graphical board and local multiplayer |
| M3.1 | Headless AI baselines, tactical evaluation, search, and reproducible experiments |
| M3.2 | Search and evaluation research, progress in long games, and history-aware performance |
| M3.3 | Worker integration, browser opponent selection, and interruptible play |
| M3.4 | Tested difficulty levels and balanced resource profiles |
| M4 | Analysis, puzzles and replay tools |
| M5 | Online multiplayer and rankings |
| M6 | Advanced AI personalities and self-play optimisation |
| M7 | Additional historical reconstructions |

M2 begins after independent review of the M1 rules engine.
